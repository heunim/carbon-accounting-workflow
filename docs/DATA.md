# 数据与核算边界

背景文件的52条因子来自此前审查过的原始工作簿，经筛选和字段标准化进入本项目。未将170条候选全部设为可自动调用。运行时因子只从Excel读取，不依赖资料网站在线可用。

逐条因子保存来源URL、官方表行号或定位、年份和使用条件。NCSC是动态数据库，原始条目可能随版本变化，因此发布版本、值和计算依据一起冻结在背景文件中。

发布版本、适用年度和底层数据年份分开记录。英国2026版是发布及报告年度，不代表每个因子的底层数据都来自2026年；无法明确确定的数据年份留空，不能填成发布年份。电力因子的数据年份为2023。

## 增加因子

在因子库新增一行，保持ID唯一，填写活动类型、物质标签、地区、国家、方法、因子值、活动单位、排放表示、气体质量单位、GWP键、GWP口径、年份、核对状态和来源。已有活动类型可以直接匹配；新增类型时同步扩展类别框架和归类规则。

支持的排放表示为CO2、CO2e或GWP表中有明确条目的气体。活动单位支持质量、体积、标准体积、能量、距离、人公里、车公里和吨公里的有限集合。生物源单列、R22等总量外气体和RF不应伪装成普通综合CO₂e因子加入主小计，本版未实现这些特殊项目的正式报告。

核对状态统一为`已核实`或需要人工确认的其他文字。真实0允许使用，空值禁止计算。若添加带公式的Excel因子，须用Excel先重新计算并保存缓存，或者将核实后的数值填入因子值。程序不执行Excel公式。

没有适用中国高铁因子时保留缺口。不能把英国铁路默认当作中国高铁，也不能为了让所有记录完成而填0。

## 使用限制

项目只展示范围1/2/3大类，并未完成范围3十五类别清单。已计算小计不代表未覆盖活动的排放为零。只使用CO₂燃料因子时，备注未补齐CH₄和N₂O。正式报告是否允许排除某气体，需要另按适用规则判断。

中国购电假设情景仅计算剩余电量与所选因子的乘积。没有属性凭证核验，不将该情景称为符合GHG Protocol的实际市场法结果。
